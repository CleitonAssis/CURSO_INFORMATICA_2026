1. O que é HTML?

HTML (HyperText Markup Language) é a linguagem padrão para criar páginas web. HTML usa tags ou elementos para estruturar o conteúdo de uma página.

Cada tag é delimitada por colchetes angulares e geralmente possui uma tag de abertura e outra de fechamento.

Exemplo de Estrutura Básica:

                <!DOCTYPE html>
                <html lang="pt-BR">
                    <head>
                        <meta charset="UTF-8" />
                        <meta name="viewport" content="width=device-width, initial-scale=1.0" />
                        <title>Título da Página</title>
                        <style>
                            Estilos CSS internos podem ser adicionados aqui.
                        </style>
                    </head>
                    <body>
                        <h1>Olá Mundo!</h1>
                    </body>
                </html>

2. Elementos de Texto

HTML oferece vários elementos para estruturar o texto de forma semântica:

Títulos (Headings)

Existem 6 níveis de títulos: <h1> até <h6>
A hierarquia funciona assim:

Exemplo:

Isso é um H1

Isso é um H2

Isso é um H3

Isso é um H4

Isso é um H5
Isso é um H6

Parágrafos e Formatação

  • <p> - Define um parágrafo
  • <strong> - Texto importante (negrito)
  • <em> - Texto enfatizado (itálico)
  • <br> - Quebra de linha
  • <hr> - Linha horizontal

3. Listas

Listas Não-Ordenadas

Usam o elemento <ul> e <li>:

Exemplo:

                <ul>
                    <li>Primeiro item</li>
                    <li>Segundo item</li>
                    <li>Terceiro item</li>
                </ul>

Listas Ordenadas

Usam o elemento <ol> e <li>:

Exemplo:

                <ol>
                    <li>Primeira etapa</li>
                    <li>Segunda etapa</li>
                    <li>Terceira etapa</li>
                </ol>

4. Links e Imagens

Links

O elemento <a> cria links (âncoras) para outras páginas:

Exemplo:

                <a href="https://www.google.com">Visite o Google</a>

Imagens

O elemento <img> insere imagens na página:

Exemplo:

                <img src="imagem.jpg" alt="Descrição da imagem" width="200">

5. Formulários

Formulários permitem que os usuários insiram dados:

Exemplo de Formulário:

                <form>
                    <label>Nome:</label>
                    <input type="text" name="nome"><br><br>

                    <label>Email:</label>
                    <input type="email" name="email"><br><br>

                    <label>Mensagem:</label><br>
                    <textarea name="mensagem" rows="4" cols="50"></textarea><br><br>

                    <input type="submit" value="Enviar">
                </form>

Campos Comuns em Formulários:

  • <label> - Etiqueta para o campo de entrada
  • <input type="text"> - Campo de texto
  • <input type="email"> - Campo de email
  • <input type="password"> - Campo de senha
  • <textarea> - Área de texto
  • <select> - Lista suspensa
  • <input type="submit"> - Botão de envio
  • <input type="checkbox"> - Caixa de seleção

6. Tabelas

As tabelas são usadas para exibir dados em linhas e colunas:

Exemplo de Tabela:

Tag Descrição
<table> Define a tabela
<tr> Define uma linha
<th> Define um cabeçalho
<td> Define uma célula de dados

7. Tags Semânticas Modernas

HTML5 introduziu tags semânticas que melhor descrevem o conteúdo:

  • <header> - Cabeçalho da página
  • <nav> - Navegação
  • <main> - Conteúdo principal
  • <section> - Seção temática
  • <article> - Artigo independente
  • <aside> - Conteúdo lateral
  • <footer> - Rodapé da página

8. Atributos Globais Importantes

Estes atributos podem ser usados em quase todas as tags:

Atributo Descrição
id Identificador único do elemento
class Classe para aplicar estilos CSS
style Estilos CSS inline
title Tooltip ao passar o mouse

9. Boas Práticas

  • ✓ Sempre use <!DOCTYPE html> no início
  • ✓ Sempre feche as tags corretamente
  • ✓ Use HTML semântico para melhor acessibilidade
  • ✓ Ajude a acessibilidade com atributos alt em imagens
  • ✓ Mantenha o código indentado e organizado
  • ✓ Use nomes descritivos para IDs e classes
  • ✗ Não aninhe tags de forma incorreta
  • ✗ Não use HTML inline para estilo, use CSS sempre que puder.
